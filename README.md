# Data and Model for Soccer Analytics

## Bachelor's Thesis Project

This repository contains the Python implementation of the data analysis and machine learning procedures developed for the bachelor's thesis titled **"Data and Model for Soccer Analytics."**

The project uses FIFA 19 player data from the 2018–2019 season to explore player attributes and identify different player profiles through K-Means clustering.

## Project Objectives

* Explore and understand FIFA 19 player data.
* Perform data cleaning and preprocessing.
* Conduct Exploratory Data Analysis (EDA).
* Visualize player attributes and their distributions.
* Apply the Elbow Method to select the number of clusters.
* Use Principal Component Analysis (PCA) for dimensionality reduction and visualization.
* Apply K-Means clustering to identify player profiles.

## Methods and Technologies

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Scikit-learn
* Principal Component Analysis (PCA)
* K-Means Clustering

## Repository Structure

The repository will contain:

* `analysis.py` – Python implementation of the analysis.
* `requirements.txt` – Required Python libraries.
* `figures/` – Visualizations generated during the analysis.
* `README.md` – Project documentation.

## Dataset

The analysis is based on FIFA 19 player data for the 2018–2019 season.

The dataset is used to examine player characteristics and perform clustering based on selected football attributes.
